# Amazon Sales Performance & Profitability Analysis

## Project Overview
This project presents an end-to-end data analytics solution to analyze Amazon sales performance and profitability. The objective is to transform raw sales data into actionable business insights using data cleaning, analysis, and visualization techniques.

## Business Objectives
- Analyze overall sales and revenue trends  
- Measure product and category-wise profitability  
- Identify top-performing and underperforming products  
- Track key business KPIs  
- Provide data-driven recommendations  

## Dataset Description
The dataset contains Amazon sales transaction data with the following fields:
- Order ID  
- Order Date  
- Product / Category  
- Quantity Sold  
- Sales Revenue  
- Cost  
- Profit  
- Profit Margin
